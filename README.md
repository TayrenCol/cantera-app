# cantera-app
SaaS multi-tenant para la gestión integral de escuelas deportivas. Automatización de expedientes digitales, seguimiento documental y administración de pagos recurrentes.

## Arquitectura y Entornos
* **Branch Principal (`main`):** Producción / Entorno estable.
* **Branch de Integración (`dev`):** Staging / Pruebas de desarrollo.
